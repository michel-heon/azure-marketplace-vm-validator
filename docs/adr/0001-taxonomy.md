# ADR 0001 — Test taxonomy

## EN
Conformance checks are grouped by certification chapter (200.3.3, 200.4, 200.5)
and implemented as one-file-per-requirement in `/tests`.

## FR
Les contrôles de conformité sont groupés par chapitre de certification (200.3.3, 200.4, 200.5)
et implémentés selon le principe un fichier par exigence dans `/tests`.
